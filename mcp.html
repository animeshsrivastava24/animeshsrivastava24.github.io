MCP servers.

Model Context Protocol servers let an AI assistant call real tools. I am building two that give LLMs the context embedded work needs: register maps and crash dumps.

01How it fits

02Servers

SERVER 01 · regmap-mcpIn progress

Register maps, not guesses.

LLMs often invent register bit positions. regmap-mcp loads CMSIS-SVD files for STM32 parts and answers from the vendor's own register map: peripherals, registers, fields and reset values.

  • Python
  • MCP SDK
  • CMSIS-SVD
  • STM32
# tools
list_peripherals(device)
    → [GPIOA, RCC, USART1, …]
get_register(device, periph, reg)
    → address, reset value, fields[]
decode(device, periph, reg, value)
    → { "MODER5": "0b10 · alternate function", … }
encode(device, periph, reg, fields)
    → 0x0000_0800
SERVER 02 · faultdump-mcpIn progress

Post-mortems for Cortex-M crashes.

Takes a HardFault dump captured over UART (stacked registers plus CFSR, HFSR, MMFAR and BFAR), decodes the fault cause and maps PC and LR back to source lines using the ELF file.

  • Python
  • MCP SDK
  • ARM Cortex-M
  • ELF / DWARF
# tools
decode_fault(dump)
    → cause, faulting address, notes
stack_frame(dump)
    → r0–r3, r12, lr, pc, xpsr
symbolize(addr, elf)
    → "rf_drv.c:212 · rffe_write()"
last_faults(n)
    → the n most recent dumps from the log

Both servers are in progress. This page will link to their repositories when they are public.
